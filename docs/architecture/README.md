# Architecture Decision Records

Decision records for `kg-cloud`. Each ADR captures one significant deployment or
topology decision, its context, and the alternatives weighed.

| ADR | Title | Status |
|-----|-------|--------|
| [001](ADR-001-hybrid-cloudflare-railway-deployment.md) | Hybrid Cloudflare + Railway Deployment Topology for Kappa Graph | Proposed |

## Conventions

- Filename: `ADR-NNN-kebab-title.md`, zero-padded sequential numbers.
- Frontmatter: `status`, `date`, `deciders`, `related`.
- Status lifecycle: `Proposed -> Accepted -> (Superseded by ADR-NNN)`.
- One decision per ADR; supersede rather than rewrite history.
